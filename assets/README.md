# Visual assets

physics-graph-social-preview.png is a publicity illustration for the repository.
It is not an experimental result and does not depict the exact 305-node graph.
The built-in OpenAI image generator created it on 2026-08-25 from a prompt for
a wide scientific-educational banner in which blue quantity nodes, amber
operator nodes, and green law nodes converge on one hidden quantity. A second
editing pass removed named laws and full equations to avoid implying a specific
scientific derivation.

The exact implemented graph remains cm_fullgraph_v1.json, and the manuscript's
mass-route figure is generated deterministically from its LaTeX/TikZ source.
